# Spare v0.1.0

Release date: 2026-10-22 (planned). First public version.

## What is in

- Menu bar item (the Spare ring and free GB) with a panel for Disk, Memory and Today's recommendation; alerts for low disk and high memory.
- "Analyze everything": one scan of disk and memory, with progress and Stop.
- Cleanup by category with Safe or Review badges, a review screen, a confirmation, live progress, a result with Undo and "Free it now", and History.
- Largest files (Show in Finder, Move to Trash), Memory (the 15 heaviest processes, graceful quit) and Settings (alert limit, project folders, idle days, open at login).
- `spare` CLI with the same engine and JSON output.
- English and Brazilian Portuguese, dark theme, app icon.
- Unnotarized, ad-hoc signed, Apple Silicon only. Install: see the README ("Open Anyway").

Verify with `shasum -a 256 -c Spare-0.1.0.dmg.sha256` next to the download. The `.dmg` is rebuilt for the final release: the checksum published with the GitHub Release is the one that counts.

## Rollback

There is no previous version. To roll back: delete the GitHub Release and the `v0.1.0` tag (`gh release delete v0.1.0 --cleanup-tag`). Users who installed it can drag Spare to the Bin; Spare keeps only `~/Library/Application Support/Spare` (history, settings), which they can remove too. Cleanups it made can be undone from History while the items are still in the Trash.
